## Idea en una frase (para decirle al dueño)
"El mayoreo lo dejamos en la web como un módulo aparte: tú armas el pallet,
le pones foto y precio, y el mayorista lo aparta solo. No se mezcla con la
venta por pieza."

## Menudeo vs. mayoreo — no mezclar
- Menudeo = por pieza única. Código único, foto, precio, Disponible / Apartado / Vendido.
  Ej. `LAB-TOM-CAM-H-M-AZUL-001`.
- Mayoreo = por pallet cerrado. El pallet es UN solo lote, no piezas sueltas.
  En la web se publica como un producto: foto del pallet, qué trae, cuántas
  piezas, marcas, tallas, condición, precio por pallet y cuántos quedan.

## Lo que automatiza
1. Publicar el pallet en web + aviso por WhatsApp a su lista de mayoristas.
2. Apartado con tiempo límite; si no paga, se libera solo.
3. Al venderse, ese pallet desaparece del inventario — no queda disponible
   para menudeo. Cero doble venta y cero contestar "¿qué trae el pallet?"
   20 veces por WhatsApp.
4. Historial de quién compra, qué pallet y cada cuándo, para recontactarlo
   cuando llegue mercancía parecida.

## Para cotizarlo faltan 3 datos — preguntar al dueño, no inventar
1. ¿Qué es un pallet para él? ¿Cuántas piezas, mixto o por categoría?
2. ¿A qué precio lo vende hoy y a quién? ¿Ya tiene lista de mayoristas?
3. ¿Cada cuándo arma pallets y cuántos vende al mes?

Sin esos 3 datos no hay precio final para este módulo.
